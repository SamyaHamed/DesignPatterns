# Design Patterns 

# 🎨 Design Patterns in Python

This repository contains practical and easy-to-understand implementations of common **software design patterns** using **Python**.

The main purpose of this repository is to demonstrate how design patterns can be applied in real-world scenarios to write cleaner, more reusable, and more maintainable code.

---

## 📌 What Are Design Patterns?

Design patterns are reusable solutions to common problems in software design.  
They represent best practices used by experienced developers and help structure code efficiently.

---

## 🧩 Patterns Included

This repository includes examples of different types of design patterns, such as:

- Creational Patterns  
- Structural Patterns  
- Behavioral Patterns  

Each pattern is implemented using simple Python examples.

---

## 🧠 Decorator Pattern Example

One of the files in this repository demonstrates the **Decorator Pattern**.

### 🔹 Description
The Decorator Pattern allows adding extra functionality to an existing function without modifying its original code.

In this example, a decorator is used to measure the execution time of different functions, such as preparing tea or matcha.

### 🔹 Concepts Covered
- Function decorators
- Higher-order functions
- Code reusability
- Execution time measurement
